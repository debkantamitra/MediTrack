# MediTrack Learning Plan

This plan builds MediTrack one milestone at a time. Each milestone teaches a Java concept, connects it to a design decision, and adds a working piece of the application.

## Milestones

1. Java setup, JVM basics, and first runnable app.
2. Package structure and Java basics.
3. Abstract base entities.
4. Doctor and Patient inheritance.
5. Encapsulation and validation.
6. Collections and generic `DataStore<T>`.
7. CRUD services.
8. Search and polymorphism.
9. Appointments and custom exceptions.
10. Billing, immutability, and interfaces.
11. Cloning and deep vs shallow copy.
12. File I/O and command-line loading.
13. Design patterns where they naturally fit.
14. Streams, lambdas, and analytics.
15. Intro concurrency.
16. Manual tests, JavaDocs, and final docs.

## Per-Milestone Format

Each milestone should answer:

- What are we building?
- Why are we building it now?
- Which Java concept does it teach?
- Which SOLID principle or design pattern applies?
- What would go wrong without this design?
- What is the smallest useful implementation?
- How do we verify it?
- What should the learner try independently?
